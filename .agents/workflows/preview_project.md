# Preview Project Workflow

This workflow details how to start the development preview server and verify the frontend application locally.

## Step 1: Start the Development Server
Launch the Next.js development server:
```bash
npm run dev
```
*(By default, this project is configured to run on port 9002)*

## Step 2: Access the Application
Open your web browser and navigate to:
[http://localhost:9002](http://localhost:9002)

Verify that the site renders without errors and all links are functional.
