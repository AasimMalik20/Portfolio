# Directory Rules: src/components/

> **Applies to**: `src/components/` and subdirectories

---

## Structure

```
src/components/
├── ui/              # shadcn/ui primitives — DO NOT manually edit
├── theme-provider.tsx
├── theme-toggle-button.tsx
└── [new components go here]
```

---

## Rules for `src/components/ui/`

1. **Generated by shadcn/ui CLI only** — `npx shadcn-ui add <name>`
2. **Do not hand-modify** these files unless you have a very specific reason. Changes will be overwritten when the component is regenerated.
3. If customization is needed, create a wrapper component in `src/components/` that composes the ui primitive.

---

## Rules for `src/components/` (Custom Components)

4. All custom reusable components live here (NOT inline in `page.tsx`).
5. File naming: `kebab-case.tsx`
6. Each file exports one primary component.
7. Mark with `'use client'` only if the component uses hooks or browser APIs.
8. New section components go in `src/components/sections/` (subdirectory to be created).

---
